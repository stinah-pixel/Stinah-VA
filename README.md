# Stinah VA — Site vitrine

Site one-page (HTML statique) pour l'activité d'assistante virtuelle de Stinah VA.

## Contenu du dossier
```
stinah-va-site/
├── index.html      ← le site complet (à ouvrir / héberger)
├── README.md       ← ce fichier
└── assets/
    ├── hero-wide.jpg       ← photo d'accueil
    └── about-portrait.jpg  ← photo "Qui suis-je"
```

## Mettre en ligne sur GitHub Pages (gratuit)

1. Sur https://github.com → bouton **New** pour créer un dépôt **public**, nommé par ex. `stinah-va`.
2. Sur la page du dépôt vide, cliquez **« uploading an existing file »**.
3. Glissez-déposez le **contenu** de ce dossier : `index.html`, `README.md` **et le dossier `assets/`**.
   (Déposez le contenu, pas le dossier parent — `index.html` doit être à la racine du dépôt.)
4. Cliquez **Commit changes**.
5. Allez dans **Settings → Pages**.
6. Section *Build and deployment* → *Source* : **Deploy from a branch**.
7. *Branch* : **main**, dossier **/(root)** → **Save**.
8. Attendez 1–2 minutes. Votre site sera en ligne à :
   `https://VOTRE-PSEUDO.github.io/stinah-va/`

### Nom de domaine personnalisé (optionnel)
Si vous avez un domaine (ex. `stinah-va.com`), vous pouvez le brancher dans
**Settings → Pages → Custom domain**. Je peux vous guider si besoin.
